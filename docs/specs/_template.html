⑧ 결정사항 / 미해결 질문

결정 대기 + 이미 정해진 결정 모두 기록. resolved 는 지우지 말고 상태만 바꿔 결정 이력으로 남긴다. LOCK 조건: open 0건.

⚠️ 미답은 가정으로 메우지 않는다. 사용자가 답을 보류한 항목은 여기 open 행으로 남기고, 본문의 해당 위치에도 [NEEDS CLARIFICATION: 구체 질문] 을 그대로 써 둔다. LOCK 게이트가 이 문자열을 grep 으로 확인하므로, 마커가 하나라도 남으면 locked 로 갈 수 없다. (예: [NEEDS CLARIFICATION: 개통 후 날짜 변경도 허용하나? 아니면 미개통만?])
