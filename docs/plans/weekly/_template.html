🧭 작업 규칙 리마인더

  • monorepo 빌드 의존: design-tokens → design-vue → admin/client. DS 변경은 두 Nuxt 앱 모두 재배포 트리거 (path filter 설계 시 반영)
  • DS API 변경 시 packages/design-*/package.json version bump (외부 consumer 영향 시)
  • 모바일 앱은 Expo managed 유지. metro.config.js 만들지 말 것 (SDK 52+ 자동 monorepo 지원)
  • iOS eSIM 설치는 Universal Link (esimsetup.apple.com) 만 사용. CoreTelephony entitled API 경로는 MVNO 영구 불가
  • Maya API 연동은 apps/client/server/api/v1/* Nitro 엔드포인트 단일 소스. mobile 도 동일 엔드포인트 호출 (backend 추가 작업 X)
  • 위임 가능 작업은 Morty (frontend) / Noob Noob (mobile) 우선 고려. 단 인프라/CI/CD/배포는 John 직접
  • prod 배포 직전엔 m8fe-prod-push-check 류 skill 도입 후 사용 (현재 nomacom 용은 미정 — A 트랙 안정화 후 결정)
  • docs/ 는 .gitignore 가 적용된 상태에서만 운영 (공유는 Notion / Slack 등 별도)
