### 3.2 한국 시장 (마이리얼트립 · 도시락 · 말톡) 특화

- **결제 혜택 배지** — 네이버페이 포인트, 카카오페이/토스 즉시할인, 무이자 24개월. 한국 OTA 의 시각적 무게 중심.
- **유선 고객센터 번호** — 1566-9070, 1670-8208 등 명시. 글로벌엔 없음, 한국엔 강력한 trust signal.
- **ISMS-P · KICC 에스크로 · 사업자등록 · 통신판매신고** 배지 줄.
- **"누적 판매 N건"** 카운터 (말톡 1,000만 등) — 별점/리뷰보다 한국에서 효과 큼.
- **현지 통신사 로고** (Softbank, KDDI au, Docomo).
- **070 무료통화 부가가치 번들** (도시락/말톡 100분, 60분).
- **호환기기 모델명 구체화** — iPhone XS+, Galaxy Flip4/Fold4+ 까지.
- **취소/환불 정책 카드** — 시점별 환불율 명시.

### 3.3 우리만 강조할 차별화 축 (현재 페이지에 이미 있는 자산)

- **시작 일시 예약** — 글로벌/한국 어디서도 강하게 어필 안 함. 우리는 이걸 hero CTA 직하에 못 박을 만한 무기.
- **Maya B2B 자체 정책 통제** — 소진 후 저속 무제한 등 정책 옵션이 우리 손에. 마케팅 카피화 가능.
- **한국 고객센터** — Holafly 의 "24/7 multilingual" 보다 한국에서는 "한국어 상담" 이 더 효과적.

## 6. 구현 단계

이 페이지는 단일 HTML 파일이고 빌드 의존성 없음. 한 번에 다 작성해도 무방하지만 검수 편의를 위해 3 단계로 끊는다.

### Phase 1 — H 항목 (블로커)

- 02 Trust strip
- 03 Plan matrix (가격은 placeholder 로 시작 — 실제 가격은 별도 확정 필요, §7 참조)
- 04 Payment benefits (네이버 스마트스토어 입점이므로 실 노출 가능한 결제수단만 — §7)
- 07 후기 캐러셀 (사진은 placeholder → 실 캡처 교체)
- 14 신뢰 배지 줄

→ Phase 1 끝나면 PNG 한 번 출력해서 검수.

### Phase 2 — M 항목

- 10 비교 표
- 02·14 신뢰배지 보강
- 08·11 Coverage/Compatibility 디테일
- 12 환불 정책 카드
- 13 FAQ 확장

### Phase 3 — L 항목 (선택)

- 데이터 사용량 계산기, 여행 팁 카드, 신규 쿠폰 등
- 다음 차수로 미뤄도 됨

## 7. Open Questions — 콘텐츠 확정 필요

본격 작성 전에 사실 확인이 필요한 항목. 답이 안 정해진 채로 placeholder 로 채우면 PNG 출력 후 재작업 발생.

| Q | 항목 | 결정 필요 사항 | 임시 placeholder 시 표기 |
|---|---|---|---|
| Q1 | 누적 판매 수 | 실 누적 건수 또는 "N+" 표기 형태 | "18,000+" (이전 카피에 등장 — 사실 확인 필요) |
| Q2 | 네이버 별점 | 현재 스마트스토어 평점 (4.X) | "★ 4.8 (예시)" |
| Q3 | 재구매율 | 실 데이터 또는 미노출 | 미노출 옵션 |
| Q4 | 플랜 가격 6개 | 1·3·5·7·15·30일 각각 정가 + 할인가 | 가짜 가격 + "예시" 워터마크 |
| Q5 | 결제 혜택 — 적용 카드사 | 네이버 스마트스토어 입점이면 결제수단 = 네이버 결제 일부. 외부 카드사 즉시할인은 적용 불가일 수 있음 | "네이버페이 N% 적립" 정도만 명시 |
| Q6 | 후기 5건 | 실 후기 가져오기 (스마트스토어 노출 동의 확인) vs 가상 인용 | "가상 인용 — 실 후기 교체 예정" 워터마크 |
| Q7 | 호환기기 정확한 리스트 | Apple/Samsung 공식 호환 모델 — 우리 자체 확인된 것만 | "공식 발표 기준" 출처 표기 |
| Q8 | 통신사 로고 사용권 | Softbank · KDDI au 로고 → 라이선스/사용 가이드 확인 필요. 부적격 시 "주요 통신사 망" 텍스트로 대체 | 텍스트 fallback |
| Q9 | "Featured in" 미디어 | 노출된 매거진/블로그 있나? 없으면 L6 으로 미룸 | 미사용 |
| Q10 | 사업자/통신판매신고 번호 | 실 번호 (admin 시스템 / nomacom 법인 등기부) | "준비 중" 표기 |
| Q11 | KICC 에스크로 | 네이버 결제 사용이면 별 의미 없을 수 있음 — 굳이 노출 안 해도 됨 | 미사용 검토 |
| Q12 | 무이자 24개월 | 네이버페이/카드사 정책 확인 — 모든 카드 적용인지 일부인지 | "최대 N개월" 모호 표기 |

→ 답안을 미리 모아주시면 Phase 1 작성 때 한 번에 박아 넣을 수 있습니다. 답 미정 항목은 위 "임시 placeholder" 표기로 작성 후 교체.

## 8. 비결정 / 향후 검토 사항

- **카피 톤 재정렬**: 현재 카피는 "잘 만든 글로벌 영문 사이트의 한국어판" 톤. 한국 마케팅 카피는 더 직설적·숫자 중심·이모티콘/특수문자 빈도가 높음. 한국식 톤으로 전면 재작성할지 (= 더 잘 팔리지만 디자인 톤 깨질 가능성) vs 유지할지 결정 필요.
- **단일 페이지 vs 시리즈**: 일본 7일 외 다른 상품 (대만, 동남아, 유럽 등) 도 만들 거면 컴포넌트화 검토. 현재는 단일 HTML이라 복사-수정 패턴이 빠르지만 유지보수 비용 증가.
- **반응형 vs PNG 전용**: 현재 860px 고정. PNG export 목적이면 이대로 OK. 만약 웹 페이지로도 호스팅하려면 mobile breakpoint 추가 필요.
- **html-to-image 한계**: 매우 긴 페이지 (6000px+) 출력 시 메모리/시간 이슈 가능. Phase 2 끝나면 실제 PNG 출력 테스트 → 필요 시 Playwright 스크립트 옵션 재고.
