환불 불가 — 본문도 단정형으로 통일 완료

13-refund

큰 라벨은 환불 불가인데 바로 아래 본문은 환불이 어렵습니다입니다. 「어렵다」는 여지가 있다는 뜻으로 읽히고, 실제로 그 틈으로 환불 요청이 들어옵니다. 규정 문구에서 다중 완곡은 분쟁을 부릅니다.

현재 QR 스캔으로 eSIM 을 폰에 등록 (설치) 하면 환불이 어렵습니다. 설치 전 호환 기기 · 여행 일정 확인 부탁드려요.
적용 완료 QR을 스캔해 eSIM을 폰에 설치하면 환불되지 않습니다. 설치하기 전에 호환 기기인지, 여행 일정이 맞는지 꼭 확인해 주세요.

P3-1

text-wrap 미적용 — 전체 0회

shared/base.css

제목 줄 길이를 고르게 맞추는 balance, 문단 마지막 줄에 단어 하나만 떨어지는 것을 막는 pretty 둘 다 없습니다. 860px 고정 폭 캔버스라 제목이 「데이터 넉넉히,」 / 「길게.」 처럼 어색하게 쪼개질 때 직접 개입해야 하는데, 이 두 줄이면 브라우저가 알아서 처리합니다. 

/* shared/base.css 에 추가 */
h1, h2, h3, h4,
.section__title,
.hero__title      { text-wrap: balance; }   /* 짧은 텍스트 전용 */

p, li,
.section__lede,
.ds-card__body    { text-wrap: pretty; }    /* 외톨이 단어 방지 */
Chrome/Edge 117+, Safari 17.4+ 지원. Firefox 는 미지원이지만 그냥 기본 동작으로 퇴화할 뿐이라 지금 넣어도 안전합니다. PNG 내보내기는 html-to-image 가 Chromium 엔진을 쓰므로 그대로 반영됩니다.
해결

letter-spacing — 본문·캡션만 0 복귀 (결정 5 반영)

shared/tokens.css + _generator/templates

korean-web-copy 스킬은 「Pretendard 는 자간이 폰트에 설계돼 있으니 건드리지 마라」고 못 박습니다. 그런데 이 프로젝트는 2026-09-10 에 자간 토큰 6종을 확정했고 (--ls-display-lg: -0.03em … --ls-caption: -0.005em) 56곳에서 사용 중입니다.

스킬의 경고는 「본문에 자간을 임의로 주지 마라」는 뜻이고, 여기 토큰은 크기 구간별로 음수 자간을 주는 디스플레이 타이포 규칙이라 범위가 다릅니다. 대형 제목(28px+)의 -0.03em은 업계 표준에 가깝지만, 작은 글씨에서 자간을 좁히면 한글 가독성이 떨어집니다.

변경 전 --ls-body: -0.01em
--ls-caption: -0.005em
변경 후 — 적용 완료 --ls-body: 0
--ls-caption: 0

--ls-display-lg · --ls-display · --ls-heading · --ls-eyebrow는 그대로 유지했습니다. southern-eu/shared/와 _generator/templates/shared/ 양쪽 모두에 반영해 새로 만드는 상품 페이지도 같은 값을 씁니다.
