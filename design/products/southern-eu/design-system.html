3. letter-spacing 규칙

값을 개별로 정하지 않고 크기 구간으로 결정합니다. 큰 글자일수록 더 좁힙니다 (한글 특성).

구간 토큰 값 적용 대상
24px 이상 --ls-display −2.2% 섹션 타이틀 · 큰 수치
18–23px --ls-heading −1.5% 카드 헤딩 · 서브 헤딩
15–17px --ls-body −1% 서브타이틀 · 본문 ← 확정됨
14px 이하 --ls-caption −0.5% 캡션 · pill · 각주
대문자 라벨 --ls-eyebrow +14% eyebrow (uppercase 시 자간 확대)
정리 대상 — −0.03em → −0.015em (heading 구간) · −0.02em → −0.022em (display) · 0.04em / 0.02em → eyebrow 외 양수 자간 폐지

9. 확정 후 진행

이 페이지 confirm 이후의 순서입니다.

# 작업 내용
1 토큰 승격 --fs-* --ls-* --sp-* --lh-* 를 shared/tokens.css 에 추가
2 base.css 재정의 .eyebrow .section__title .section__lede + 신규 .ds-card / .ds-note / .ds-pill / .ds-tile
3 14개 섹션 마이그레이션 px 직접값 → 토큰 치환. 렌더 diff 로 회귀 확인
4 Figma 반영 재캡처 불가 — 사용자 수정 9건이 지워짐. 텍스트 스타일을 Figma 에 만들고 노드에 속성만 적용
5 10개 zone 전파 _generator/templates/ 갱신 후 재생성
4번이 이 트랙의 제약입니다. Figma 쪽엔 직접 수정하신 텍스트 9건이 있어 재캡처로 밀어넣을 수 없습니다. 타이포 스케일은 Figma Text style 로 만들어 노드에 적용하는 방식이어야 합니다.
